# 年度回顧需要的資料欄位

已經有的（2026_PPA_會員分級機制 + 階級表抽樣）：
- 五階級定義與門檻：岩石 / 青銅 / 白銀 / 鉑金 / 黑鑽
- 各階級會員數、佔比、ARPU
- 升級門檻（終身累積淨消費）與保級門檻
- 黑鑽隔年留存率

## 還需要的

### A. 個人層級（每位會員一列，ID 雜湊後即可）
| 欄位 | 用在哪張卡 | 沒有的話 |
|---|---|---|
| 當前階級 | 全部 | 無法分版 |
| 終身累積淨消費 | 升級門檻卡 | 算不出「再 X 元升級」 |
| 今年消費金額 | 猜猜你花多少、同比 | 三張卡開天窗 |
| 去年消費金額 | 同比卡 | 同比卡拿掉 |
| 今年總學習時數 | 賭一把排名、時段卡 | 目前全靠推算 |
| 今年完成單元數 | 岩石版本主數字 | 岩石版本沒有主數字 |
| 登入天數 | 關係狀態卡 | |
| 學習時段分佈（24 小時） | 學習人格卡 | 人格卡拿掉 |
| 觀看時數最高的老師 + 該老師時數 | 老師卡、Clips 接通 | 老師卡拿掉 |
| 該老師未購課程清單 | 老師的其他課（轉換最高的一張） | 這張拿掉 |
| 子分類購買/觀看分佈 | 領域圖鑑、猜主戰場 | 兩張卡拿掉 |

### B. 分佈層級（每個指標一列，這比個人資料重要）
| 指標 | 需要 |
|---|---|
| 學習時數 | 中位數、各階級平均、百分位門檻 |
| 完成單元數 | 同上 |
| 今年消費金額 | 各階級平均（分級表只有終身累積 ARPU） |

### C. 受眾規模
- 岩石階級今年真的看過內容的人數（120 萬裡有多少不是殭屍帳號）
- 黑鑽裡今年消費未達 10,000 的人數（保級卡的實際受眾）

## 已發現的資料問題
1. 階級表同一會員 ID 在同一秒有兩筆不同階級（鉑金 / 白銀），這張表是變動歷程而非當前狀態，取當前階級需要額外邏輯。
2. 階級時間戳大量集中在 2026-01-28 11:07，是制度上線的批次灌檔值，不是真實升級日。「你在 X 月升級」文案只能對批次日之後的人使用。
3. 分級機制表寫「石頭」，實際資料是「岩石」，文案以實際資料為準。
